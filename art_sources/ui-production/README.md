# 全界面 UI 美术 · 2026-09-20

本轮接续战场资源重制，重点是整套游戏界面，而非继续堆角色图。靛青漆木、旧金包角、冷绢纸和朱红主按钮统一登录、大厅、军械库、战斗 HUD、兵营、准备、属性说明、结算、商店及抽奖。

## 接线与边界

`presentation/ui-theme.css` 是统一皮肤；`uiArt.ts` 是资源映射；`main.ts` 保留全部既有 DOM id 和业务接口；`BattleScene.ts` 接入面板、颜色和装饰。手机军情默认折叠；结算弹窗补齐键盘焦点约束。额外修正棋盘 42px 点击圆的相邻重叠区：由所在格子决定命中对象，避免渲染顺序抢走边缘点击；不改规则和数值。

用户实看反馈 v1 按钮装饰拉变形，v2 改成细铜边、几何回纹小角饰，并分开模式卡/长按钮/征兵/短按钮。输出不再强制压成统一宽高，运行时仅延展直边与干净中心，四角保持比例。

跨模块范围与预算见 `docs/contracts/ui-production-2026-09-20.md`。未修改共享规则、服务端、认证/经济或生产配置；本地提交不等于线上发布。

## 攻击与技能

`presentation/combatVfx.ts` 仅消费现有战斗事件，不产生伤害、选敌或网络消息。普通刀/枪/弓/骑分别使用挥斩、突刺、飞箭与骑兵残影冲击，不再统一光球换色。

| 武将 | 表现与真实机制的对应 |
| --- | --- |
| 赵云 | 五段枪芒；七进七出的半透明武将沿快照 zhaoPhantoms 坐标移动，不自行模拟往返次数 |
| 关羽、张翼 | 原技能事件驱动腾跃残影与落地斩击；关羽专属青龙刀气 |
| 张飞、关平 | 分层震波与地面尘土，区分大喝的强弱表现；不变更眩晕时间 |
| 刘备 | 金色圣剑起势与飞出，实际命中事件独立反馈 |
| 黄忠 | 火箭轨迹及真实 arrow-rain-impact 落点的燃烧落箭 |
| 黄祖 | 箭雨起势及事件驱动的连续箭矢，不用固定动画次数代替真实结算 |
| 马超、关兴、张苞 | 原晕眩事件出现时展示目标头顶眩晕星标 |
| 黄盖 | 加重骑兵冲击与扬尘；没有凭空添加主动技能 |

同时限制 36 个瞬时特效组、沿用每批普通攻击准入；低动效以短促局部命中代替飞行。飘字保留真实汇总伤害，命中数单独标记，免疫的零伤害不伪报为 1。特效图片全程等比缩放。攻击与大招优先使用屏幕中怪物的位置，后备使用真实路径坐标，避免动态绕路时错打旧路线。
