# 攻击动作帧

来源：2026-09-20 内置 image_gen 编辑，使用本项目已有 `assets/v2/troop-*.webp` 作为身份锚点，不复制原作图片。

公共提示约束：透明底、同一个人物/装备/比例/朝向、整条 4 帧一次生成、不逐帧单独生成；第 1 帧待机、第 2 帧预备、第 3 帧接触/释放、第 4 帧收招；手臂、武器、肩膀和腿须有实际关节姿势变化，不能整图旋转替代；无文字、场景、格线，武器完整。

动作提示：

- blade：盾牌防护，持刀手抬至肩后，向右下劈砍，刀低垂收招。
- spear：双手蓄力、伸臂向右刺击、收回警戒。
- bow：拉弦至脸旁，松开手指，弓弦弹回，向箭囊取箭。
- cavalry：骑手抬武器，马后腿支撑；骑手前刺、马前腿伸展；回收武器。

`tools/prepare-attack-motion.cjs` 将生成条带按已检查的间隙切分，使用一条动画共用的缩放和脚底基准。留出武器扫过的透明边距，帧 0 使用现有立绘（不是生成版本），回到同一待机姿势。源条带存在非均等边距，不能直接四等分，否则刀光/箭头被切断。导出 4 个 WebP 图集及字节清单，原始 alpha 保留；源图不在运行时加载。

边界：这是四类士兵的四姿势短动画，不是完整骨骼系统或 8 向动画；武将沿用现有独立技能资源，本次没有声称完成所有武将的身体动作帧。
