# 全界面美术与接线 · 2026-09-20

用户要求所有游戏美术到位，优先完整 UI。本任务继续承担 04 美术及 03/08 本地客户端接线、07 验收；不改 shared、认证、经济、实时联机或生产配置，不发布线上。

## 设计约定

- 题材：合字成将、双人守城。签名元素为青铜包角的军令牌，不再使用均匀的后台卡片布局。
- 材质/色：靛青漆木 #162b39、蓝灰 #365465、旧金 #d5b77c、绢纸 #e3e9df、朱红 #aa493b、亮墨 #f4ecd7。
- 字体：标题/军令使用 KaiTi/STKaiti，正文 Microsoft YaHei/PingFang SC，数字 system-ui tabular-nums。没有外部字体请求。
- 大厅：全幅原有插画 + 顶部玩家资源条 + 标题与右侧开战入口 + 道具整备。登录、房间准备、结算、商店、说明统一同套面板。
- 战场：保留 640×1386 逻辑布局；营地、BUFF、征兵互不覆盖。减少右侧重复信息，手机军情折叠，不额外挤压棋盘。验收发现相邻棋子的 42px 点击圆有 4px 重叠，改为各自格子内命中，防止点击左棋子右缘被右棋子抢走；营地命中圆不变。
- 所有 25 种原版道具使用独立可识别图标；既有 6 种局内 BUFF 图标继续使用；工具导航使用统一线性 SVG（有意的功能符号，不替代物品美术）。

## 接口与保护

- 新 `uiAssetPath`/`propIcon` 仅负责表现映射，不复制价格、概率、冷却或效果配置。
- 面板和按钮支持九宫格/边框拉伸；文字不烘焙在图中。按钮按压、禁用、选中、加载、焦点均可辨。
- 用户反馈按钮金饰拉变形后，重新生成六种用途素材；四角完整切出并等比例显示，仅直线边及中心延展，不再把横条直接拉成模式卡。
- 保留所有已有 DOM id、战斗命令、事件、快照和存档接口；新增纯表现的军情折叠。
- 资源必须来自指定 GPT 网页项目，保留原图/切片说明；位图压缩成 WebP。新的 UI 位图预算独立控制在 850,000 bytes 内，不随房间同步。
- CSS 全量预算可增至 48,000 bytes（新增完整 UI 皮肤），JS 上限保留既有 1,680,000 bytes；通过实际构建核验，不以放宽无限预算掩盖增长。
