# 规则配置合同（rules-config）

## 合同元数据

- 版本：1.5.0
- 提供方：01 规则与数值基线
- 消费方：02 权威战斗内核、03 战场交互、04 美术表现、06 实时联机、07 自动化测试
- 当前 TypeScript 来源：`packages/shared/src/config.ts`

## 已有公开配置

当前稳定消费面以 `RULES_CONFIG_1_0_9` 为主，包括 `GAME_CONFIG`、`TOKEN_POOL`、`SOLDIERS`、`GENERALS`、`GENERAL_SKILLS`、普通兵与武将各自的攻击/攻速成长、`WAVES`、难度、新手生命修正、敌军速度、Boss 配置、`MAP_LAYOUTS`、`PROPS` 及主动/被动道具 ID 集合。`LEVEL_ATTACK`、`LEVEL_SPEED` 仅作为旧武将消费者兼容别名。战斗内核、客户端和服务端只能导入这些配置，不得复制后再覆盖。

地图坐标统一使用 8×10 格号，配置原数组保持 `[x][y]`；`cellIndex`、`cellCoords`、`cellCode`、`initialOpenCells` 和 `pathPoint` 是坐标转换的共享入口。

## 配置项要求

正式 1.0 合同中的每个规则值至少包含：稳定键、明确单位、适用对象、版本、1.0.9 证据引用和允许范围。概率使用 `0..1`；时间使用整数毫秒；长度注明“格”或“像素”；倍率注明相加或相乘顺序。

下列值已经结构化并由权威模拟消费：

- 攻击碰撞盒尺寸与射程半径的 1 像素内缩；
- 普通敌军/Boss 移速与 Boss 生命倍率；
- 枪兵贯穿、骑兵范围伤害的倍率和范围；
- 主要武将技能阈值、倍率、概率、范围和眩晕时长；
- 主动道具成功概率、效果倍率、半径和持续时间；
- 农民生成/生产周期、洛阳铲周期、陨石周期和威胁范围；
- 陷阱触发范围、地雷爆炸范围与陨石清除范围。

Boss 完整技能、武将技能逐帧空间结算、推土车距离、摸金奖励链及新号铲子加权触发已经冻结。仍标为 `pending-original-verification` 的经验参与分配与部分道具调用链不得由消费者猜测或新增第二来源。

## 兼容与错误语义

- 新增字段必须有基线证据，不能仅根据现有临时代码反推为权威规则。
- `1.4.0 → 1.5.0` 仅新增可缺省技能运行时字段，恢复时由 `normalizeMatchSnapshot` 原地补齐并改写版本，不清除进行中的对局或账号道具。
- 已冻结字段改值必须提升规则版本，并附证据差异与回归夹具。
- 消费者遇到缺失的必需配置应拒绝启动对应规则，不得静默填入猜测值。
- 表现字段可以引用稳定规则键，但不得把动画时长、图片尺寸或本地化文案反向当作战斗数值。

## 测试样例

- 同一配置版本、种子、命令和固定 Tick 序列产生完全相同的 `MatchSnapshot`。
- 每个兵种和武将的攻击、间隔、范围、等级上限由配置驱动的参数化测试覆盖。
- 地图逐格编码、路线取样和攻击擦边判定使用 1.0.9 冻结夹具。

## 未决问题

- 仍为 `pending-original-verification` 的字段不得出现在“100% 原版复刻”发布声明中。
- 独立联网权威服务必须验证客户端、服务端使用同一 `rulesetVersion=1.0.9` 与 `schemaVersion=1.5.0`。
