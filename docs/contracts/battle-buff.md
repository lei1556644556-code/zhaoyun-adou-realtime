# 局内掉落 BUFF 合同

## 结论

局内 BUFF 是项目新增的实时对战互动机制，不属于原版 `1.0.9` 道具表。服务端/共享模拟负责掉落、库存、目标校验和效果结算，客户端只展示权威快照并提交使用命令。

## 掉落与库存

- 每个普通敌兵被击败时独立进行一次确定性掉落判定，概率为 `8%`；Boss 不参与。
- 掉落后从四种 BUFF 中等概率选择一种，每种条件概率为 `25%`。
- BUFF 进入击败该敌兵一方的局内库存。库存随对局快照保存，支持断线重连，但不进入账号数据库，也不跨局保留。
- 每件掉落物有唯一实例 ID；使用成功后消耗，失败命令不得消耗。

## 使用目标与效果

玩家只能把自己的 BUFF 拖到“正在进攻对手”的存活怪物身上：

| 类型 | 效果 |
|---|---|
| `invulnerable` | 目标 5 秒内免疫任何伤害 |
| `haste` | 目标 10 秒内移动速度变为 2 倍 |
| `giant` | 目标模型放大为 2 倍，当前生命和生命上限均变为原来的 2.5 倍；持续至该怪物离场，重复施加无效 |
| `rally` | 以目标为中心半径 2 格，存活怪物移动速度 +20%、当前生命和生命上限 +20%，持续 6 秒；重复施加刷新持续时间，不叠加生命增幅 |

不同来源的移速效果相乘；临时生命增幅到期时从生命上限扣回对应增量，并将当前生命夹在新的上限内。

## 命令与事件

客户端命令：

```ts
{ type: "USE_BATTLE_BUFF"; buffInstanceId: string; targetEnemyId: string }
```

权威事件：

- `battle-buff-dropped`：携带所属席位、实例 ID、BUFF 类型和掉落来源敌兵 ID；
- `battle-buff-used`：携带使用席位、实例 ID、BUFF 类型、目标所在席位、主目标 ID 和实际受影响怪物 ID。

客户端遇到未知 BUFF 类型时应忽略其表现，但不得拒绝整个快照。
