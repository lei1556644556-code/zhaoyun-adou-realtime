## 3. 实时对战实现映射

1. 玩家在大厅装配，权威状态只接受最多2主动、6被动且不重复的 `SET_PROP_LOADOUT` 命令；真人对局双方各自提交自己的装配。
2. 主动道具通过 `USE_PROP` 命令提交目标。己方单位、敌方单位、营地文字或道路格都由服务器/房主权威状态再次校验，客户端高亮不是判定依据。
3. 冷却、概率、永久增益、5秒临时减速、陷阱/地雷触发、农民和洛阳铲计时、阿斗生命与陨石清场全部写进快照，因此刷新、人机存档和真人房间重连可以继续。
4. 攻速加成使用原包的“加成值相加后作用于基础攻击间隔”模型；普通兵等级攻速为 `1 / 1.5 / 2.1 / 2.73 / 3.4125`，武将等级攻速为 `1 / 1.3 / 1.56 / 1.794 / 1.9734`。
5. 招贤榜按原包 `on.TE/FO` 使用整局持续牌库：每份姓名字独立50%复制，抽中后移除原份和至多一份同字副本；不是把所有姓名字权重固定翻倍。

## 4. 记录中的原版获得情景与网页替代

下列网页替代是明确的项目设计：凡原作看广告/分享处，本项目均改为直接获得。原作获得条件目前只有实现文档记录，没有随库调用链或实机证据，因此仍列为待核验，不把网页行为反推成原包事实。

| 时机 | 原包行为 | 当前网页行为 |
|---|---|---|
| 局内开荒补给 | 初始白色布阵格全部被占满、营地没有铲子且仍有空位时出现；一次补给最多2把铲子；首次使用免费，之后需要广告 | 只在相同条件满足时显示于局内主动道具栏，每局一次直接领取最多2把；营地无空位时不显示也不消耗机会 |
| 战斗结束 | 胜利基础20金币，失败基础5金币；广告领取可翻倍 | 结算弹窗保留单倍按钮，同时提供“原广告直接双倍”按钮 |
| 结算后商店 | 从当前仍可获得/升级的道具中均匀无放回展示3件 | 按当前记录展示3件，并写入云存档，刷新后仍为同一批商品 |
| 商店商品 | 使用原表金币价格购买；每件商品独立10%概率成为广告商品 | 普通商品扣原表金币；广告商品显示“直接领取（原广告）”且不扣金币 |
| 八格转盘 | 按 `ja` 无放回抽8个候选，再按 `Ha` 决定中奖项；入口需要广告或分享 | 沿用当前记录的候选与中奖算法，入口改成直接抽奖，每次战后商店一次 |
| 每日零点 | 清空当日道具、胜负次数等日数据；金币保留 | 按当前记录以 Asia/Shanghai 日期清空并同步 Supabase；金币保留 |

结算、待领取奖励、商店商品、转盘候选和中奖状态都保存在账号云进度中，避免刷新页面重复发奖或重抽。

## 5. 尚不能在当前战斗模型中凭空补造的内容

- 行军丹购买后给账号体力+10，但实时房间暂不消耗体力，不把它改造成战斗增益。
- 摸金校尉按当前兼容行为切换金铲外观。虽然配置文案写有“铲出宝箱”，但在开垦事件调用链补齐前，网页端不凭空增加金币或宝箱数值，也不声称“原包确定无奖励”。
- 降妖符只有在Boss实际施法事件发生时触发；普通Boss行军和普攻不虚构施法。

这些限制属于“保持原规则”而不是缺省替代：没有原包证据时，宁可不生成新数值，也不改变对局经济。
